# OOP Calculator Homework

Java / JavaFX 物件導向程式設計課程練習，使用 Maven 管理專案。

## 練習重點

- JavaFX UI 與 FXML
- Controller 事件處理
- 基礎物件導向結構
- Maven 專案管理

## 技術

`Java` `JavaFX` `FXML` `Maven`

## 直接看程式碼

- [CalculatorController.java](./src/main/java/com/example/mycalculator/CalculatorController.java)
- [MainApp.java](./src/main/java/com/example/mycalculator/MainApp.java)
- [calculator.fxml](./src/main/resources/com/example/mycalculator/calculator.fxml)

## 執行

```bash
./mvnw javafx:run
```
